# MOVAŬ — Design System

Кинетический неон 2026: **Unbounded** + volt-лайм `#C8F542` на `#08090C`.
Люди на смене — электрический фиолет `#7A5CFF`.
Не красный, не оранжевый, не Onest-заголовки, не «тихий люкс».

## Colors

| Token | Hex | Role |
|---|---|---|
| Primary | `#C8F542` | volt lime, заявки |
| On Primary | `#08090C` | |
| Secondary | `#7A5CFF` | electric violet, смена |
| Background | `#08090C` | cool black |
| Foreground | `#F4F7F0` | |
| Card | `#101214` | |
| Border | `#27272A` | |
| Muted | `#A1A1AA` | |

## Type

- Display: **Unbounded** 800, uppercase, крупно
- Body: Onest
- Неон: glow на акцентных словах

## Motion

Карта: страна целиком. Hover на город — линия маршрута, как в Яндексе, люди медленно идут к заявке.
Улицы / 3D / пролёт с телефона — ролик с живого приложения, не муляж на лендинге.
